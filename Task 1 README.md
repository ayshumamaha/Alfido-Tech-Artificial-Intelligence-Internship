# Employee Attrition Prediction

## 1. Project Overview
Employee Attrition Prediction is a machine learning project developed as part of an AI/ML internship. The project analyzes employee data and predicts whether an employee is likely to leave an organization. It uses machine learning classification algorithms to identify patterns associated with employee attrition.

## 2. Objectives
- Predict employee attrition using machine learning.
- Analyze factors associated with employee turnover.
- Compare multiple classification models.
- Evaluate model performance using standard metrics.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 4. Features
- Synthetic employee dataset generation.
- Data preprocessing and feature scaling.
- Logistic Regression model.
- Random Forest classifier.
- Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC.
- Cross-validation.
- Confusion matrix and ROC curve visualizations.

## 5. How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Run the Python program:

```bash
python employee_attrition.py
```

## 6. Output
The program displays model performance metrics, compares classification models, generates evaluation charts, and identifies the better-performing model.
