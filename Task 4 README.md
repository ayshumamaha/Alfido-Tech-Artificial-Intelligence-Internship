# Loan Approval Fairness & SHAP Analysis

## 1. Project Overview
Loan Approval Fairness & SHAP Analysis is a machine learning project developed as part of an AI internship. It predicts loan approval outcomes using synthetic applicant data and evaluates model performance across different demographic groups. It also uses SHAP-based interpretation to understand the contribution of input features to model predictions.

## 2. Objectives
- Build a loan approval prediction model.
- Analyze model performance.
- Examine fairness-related metrics across groups.
- Understand feature importance and model predictions.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SHAP

## 4. Features
- Synthetic loan dataset generation.
- Loan approval prediction using Random Forest.
- Feature importance analysis.
- SHAP-based model interpretation.
- Group-level performance comparison.
- Selection rate analysis.
- Fairness observations and recommendations.

## 5. How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn shap
```

Run the program:

```bash
python loan_fairness.py
```

## 6. Output
The program displays prediction metrics, feature importance, group-level fairness comparisons, and SHAP visualizations where supported.
