# Movie Review Sentiment Analyzer

## 1. Project Overview
Movie Review Sentiment Analyzer is a beginner-level Python project developed as part of an AI internship. The program analyzes a user's movie review and identifies whether the sentiment is positive, negative, or neutral using keyword matching.

## 2. Objectives
- Understand basic sentiment analysis.
- Process text input.
- Identify positive and negative words.
- Determine the overall sentiment of a movie review.

## 3. Technologies Used
- Python
- String processing
- Lists
- Loops
- Conditional statements

## 4. Features
- Accepts movie reviews from the user.
- Converts text into lowercase.
- Identifies positive and negative keywords.
- Counts sentiment-related words.
- Displays Positive, Negative, or Neutral results.

## 5. How to Run
No external libraries are required.

Run the program:

```bash
python sentiment_analyzer.py
```

Enter a movie review when prompted.

## 6. Output
The program displays the number of positive and negative words found in the review and determines its overall sentiment.
