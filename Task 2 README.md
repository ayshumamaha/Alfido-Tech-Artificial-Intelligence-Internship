# Deep Learning – Image or Text Classification

## 1. Project Overview
Deep Learning – Image or Text Classification is a deep learning project developed as part of an AI internship. The project uses a neural network model to classify input data into predefined categories. It demonstrates the basic workflow of deep learning, including dataset preparation, model training, evaluation, and prediction.

## 2. Objectives
- Understand the fundamentals of deep learning.
- Implement a classification model using a neural network.
- Prepare and process input data.
- Train and evaluate the model.
- Predict the class of new input data.

## 3. Technologies Used
- Python
- TensorFlow
- NumPy
- Matplotlib

## 4. Features
- Data preparation and preprocessing.
- Deep learning model development.
- Neural network training.
- Classification of input data.
- Model evaluation.
- Accuracy and loss visualization.
- Prediction on sample inputs.

## 5. How to Run
Install the required libraries:

```bash
pip install tensorflow numpy matplotlib
```

Run the program:

```bash
python rps_classifier.py
```

## 6. Output
The program trains a deep learning classification model, displays training and evaluation results, generates accuracy and loss graphs, and performs sample predictions.
